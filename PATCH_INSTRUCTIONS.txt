Pulse Tiles Hardware Images – patch v1.2.6

Upload these files into the existing sales-app folder in GitHub:
  app.js
  hardware-images.js (NEW)
  index.html
  app-version.json
  sw.js

Do NOT delete your existing data folder or other application files.

This patch looks up product photographs from the Pulse Tiles public WooCommerce Store API.
Images only appear when the retailer API allows cross-origin requests AND an exact product-name match is found.
Images remain placeholders otherwise; it does not invent or mismatch product photos.
The site API was not independently reachable in the build environment, so image delivery is NOT verified.

Install the patch, wait for deployment, and hard refresh Ctrl+Shift+R.
