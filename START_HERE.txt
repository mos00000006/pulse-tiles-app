Version 1.1.1 | 19 October 2026

The Pulse logo is transparent throughout the app, welcome screen, install
icons and quotation PDF. No white logo panels are used.

UPLOAD TO GITHUB
1. Extract this ZIP first.
2. Create a new repository, for example pulse-sales-app.
3. Upload ALL the extracted files and folders to the repository root.
   index.html, sales-app/ and data/ must sit beside each other.
   Do not upload the ZIP itself as the website.
4. In the repository open Settings > Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Select your main branch and / (root), then Save.
7. When GitHub shows your published address, open it.

No npm installation, build command, Node server or ChatGPT account is needed
to use the GitHub edition. It supports a normal repository subfolder URL as
well as a custom domain.

FIRST OPEN
The catalogue is available immediately. Enter your salesperson name and
press Open this device workspace.

The default device workspace saves customer records and quotations only in
that browser on that device. It is not a shared staff login system. Use the
PDF and CSV exports for copies. Clearing the site's browser data removes
the device records.
