Start with **START_HERE.txt**. Upload the extracted contents of this package
to the root of a GitHub repository and enable Pages for `main` / `(root)`.

This is the static GitHub edition. It includes the transparent Pulse logo,
all 1,453 catalogue entries and the sales tools. The supplied public settings
for Firebase project **pulsetiles-sales-app** are installed. Complete the
remaining database setup in **FIREBASE_SETUP.txt** before signing in.

Primary administrator: **moyanamoses006@icloud.com**, configured in the app
and Firestore rules. Complete the database access setup before the first
sign-in. Use **Manage Sales Team** to add salespeople or
additional administrators, and enable or disable staff access.

No private hosted-app credentials or BusterBuild Firebase configuration are
included. Product data and original Pulse prices are a dated snapshot.

The **Décor** section contains 262 selectable products and size options:
UV sheets, wall panels, blinds, décor tiles, cladding, mosaics, adhesives,
silicones, edging and skirting. Shared tiles keep their existing cart
identity and measuring features. All 66 blind size options use individual
SKUs and prices. Décor data was checked on 19 October 2026.
