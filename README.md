# Pulse Tiles Sales — GitHub Pages

Start with **START_HERE.txt**. Upload the extracted contents of this package
to the root of a GitHub repository and enable Pages for `main` / `(root)`.

This is the static GitHub edition. It includes the transparent Pulse logo,
all 1,350 catalogue entries and the sales tools. It opens with device storage;
**FIREBASE_SETUP.txt** explains how to enable shared staff access and records.

No private hosted-app credentials or BusterBuild Firebase configuration are
included. Product data and original Pulse prices are a dated snapshot.
